Codey Pet

智能编程健康桌面伴侣，让编程更健康、更高效

核心功能

  • 颜文字动画，表达不同状态（工作、闲置、休息、庆祝）
  • 智能活动监测，识别真实编程行为
  • 健康提醒系统，防止长时间编码导致职业病
  • 交互系统：点击、悬停、边界碰撞均有响应
  • 数据持久化：记录互动和健康统计

技术栈

  • 语言: Python 3.8+
  • GUI: Tkinter（轻量原生）
  • 活动监测: psutil + pywin32
  • 数据存储: JSON
  • 打包: PyInstaller（生成单文件 EXE）
